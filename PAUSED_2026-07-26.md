## How to restart (when legal clears)

### Phase 1: Restore app & deploy (5 min)

1. **Restore original app**:
   ```bash
   cd C:\Users\benja\Projects\apps\appealmate
   copy .public-backup-2026-07-26\app.js public\app.js
   copy .public-backup-2026-07-26\templates.js public\templates.js
   # Copy any other .js/.css/.html files that were overwritten
   ```

2. **Deploy to Netlify**:
   ```bash
   netlify deploy --prod
   ```

3. **Verify**: Open `https://appealmate-uk.netlify.app` — should load the app (not splash page)

### Phase 2: Re-enable Stripe (5 min)

1. **Go to [Stripe Dashboard](https://dashboard.stripe.com)**
2. **Developers → Webhooks**
3. **Add endpoint**: `https://appealmate-uk.netlify.app/.netlify/functions/stripe-webhook`
   - Select events: `checkout.session.completed`, `charge.refunded`
   - Copy signing secret from Stripe → paste into Netlify env var `STRIPE_WEBHOOK_SECRET`
4. **Verify**: Test payment with Stripe test card `4242 4242 4242 4242`

### Phase 3: Activate n8n workflows (5 min)

1. **Start n8n locally or on VPS**:
   ```bash
   $env:N8N_USER_FOLDER = 'C:\Users\benja\.n8n-local'
   n8n start
   # Open http://127.0.0.1:5678
   ```

2. **Activate daily-drafts**:
   - Click workflow **daily-drafts**
   - Toggle **Activate** (green switch)
   - Confirm (scheduled for 06:30 UTC daily)

3. **Optional: Activate dispatch-approved** (only if publisher credentials wired):
   - Click workflow **dispatch-approved**
   - Set internal shared key in the config
   - Toggle **Activate**

### Phase 4: Start social agent server (2 min)

```bash
cd C:\Users\benja\Projects\apps\appealmate\marketing\social-agent
npm start
# Opens approval dashboard at http://127.0.0.1:3210
```

### Phase 5: Test end-to-end (10 min)

1. **Test payment**: Fill parking appeal form → click "Unlock & Download" → Stripe test card
2. **Verify email**: Confirm confirmation email arrives (via Resend)
3. **Verify PDF**: Download should work
4. **Check logs**: Look for any errors in Netlify functions or n8n workflows
